# EcoScan
 EcoScan is a desktop application that scores a device's environmental impact, covering emissions, component age
 and potential lifespan.

 ## About

 EcoScan analyses a computer's hardware and produces a score, alongside a concise summary of it's environmental impact.
 The aim is to provide insight to users of how their own usage contributes to emissions, and e-waste, allowing for them to potentially make more informed choices in their daily lifes, and when considering new hardware.
